60초 안에 끝내십시오. 이 슬라이드에서 남길 것은 하나뿐입니다 — Go / No-Go 게이트는 그들이 내리는 결정이고, 덱 뒤쪽에 다시 나온다는 것.

왜 지금인가

VMware 갱신 시점은 2027년 3월입니다. 그 전에 세 가지가 바뀝니다.

갱신 견적은 이미 42% 유휴 상태인 용량에 대해 3년간 24억 원입니다.

  • 분당 IDC 계약이 같은 분기에 종료됩니다
  • 하이퍼바이저 호스트 4대 중 2대가 2026년에 하드웨어 지원 종료됩니다
  • 데이터 플랫폼 팀은 이미 옮겼고, 남은 입주 조직은 우리뿐입니다

.focus는 슬라이드의 나머지를 흐리게 만들어, 말하는 동안 그 숫자만 읽히게 합니다. 제목은 일부러 선명하게 둡니다.

현재 상태

  • 애플리케이션 61개, VM 214대, 소유 조직 9곳
  • 믿을 만한 현행 CMDB가 없습니다 — 디스커버리 진행 중

목표 랜딩 존

Terraform이 아니라 Bicep 기반 ALZ v4를 제안합니다. 플랫폼 조직이 데이터 자산을 이미 Bicep으로 운영하고 있기 때문입니다. 툴체인 하나, 리뷰 하나.

6R 처리 방침

하는 것

  • Rehost — 44개, IaaS로 그대로 이전
  • Replatform — 11개, 대부분 SQL → Azure SQL MI
  • Refactor — 2개, 고객 포털과 가격 산정 엔진

하지 않는 것

  • Repurchase — 3개, SaaS로 전환. 현업 소유이고 우리 몫이 아닙니다
  • Retire — 1개, 1월에 폐기
  • Retain — 0개. IDC에 남는 것은 없습니다.

Go / No-Go 게이트

  • 목표 환경에서 P1 스모크 테스트 전부 통과
  • 복제 지연 30초 미만이 한 시간 연속 유지
  • 최근 14일 이내에 롤백 리허설 완료
  • 지정된 현업 책임자가 상황 통화에 참여

애플리케이션 책임자가 Go / No-Go를 결정합니다. 플랫폼도, 프로그램 조직도 아닙니다. 우리는 근거를 제공하고, 리스크는 그들이 집니다.

리스크

발견되지 않은 의존성

디스커버리로 61개 앱을 매핑했지만, 외부 통신 의존성이 확인된 것은 38개뿐입니다. 완화책: 각 웨이브를 동결하기 전에 2주간 트래픽 캡처 기간을 둡니다.

라이선스 이전 가능성

ISV 계약 3건은 클라우드 조항이 생기기 전에 체결된 것입니다. 법무 검토가 2월 28일 예정이고, 웨이브 2의 임계 경로 위에 있습니다.

앞서 있는 부분

아이덴티티는 끝났습니다. Entra ID Connect가 11월부터 목표 테넌트에서 돌고 있어서, 인증 때문에 막히는 웨이브는 없습니다.

글꼴

기본값은 구글이 제공하는 Noto Sans KR(본문)과 Noto Sans Mono(코드)이고, _extensions/cloudpres/fonts.html에서 불러옵니다.

가진 글꼴 파일을 쓰려면 두 단계입니다. .woff2를 assets/fonts/에 넣고 fonts.html의 @font-face 주석을 푼 다음, theme.scss의 $cp-font-sans 첫 이름을 바꾸면 됩니다.

// theme.scss
$cp-font-sans: "Pretendard", "Noto Sans KR", "Malgun Gothic", sans-serif !default;

fonts.html의 <link> 세 줄을 지우고 .woff2 파일만 쓰십시오. 웹폰트를 못 받아도 Malgun Gothic으로 떨어지므로 한글이 깨지지는 않습니다.

화면 비율과 여백

슬라이드 크기와 여백은 _extensions/cloudpres/_extension.yml에 있습니다. 덱 하나만 다르게 하려면 그 덱의 머리말에 같은 키를 써도 됩니다.

width: 1280      # 16:9 (기본)
height: 720
margin: 0.06     # 0~1, 내용 둘레 여백
비율 width / height
16:9 1280 / 720
16:10 1280 / 800
4:3 1024 / 768

PDF는 화면 비율을 그대로 따라갑니다. 따로 설정할 것이 없습니다. 페이지 크기가 이렇게 정해집니다.

width × (1 + margin) × height × (1 + margin)

그래서 margin을 키우면 화면과 PDF 양쪽에서 여백이 같이 늘어납니다.

margin은 화면과 PDF에 함께 적용됩니다. PDF 에만 더 주려면 print-clean.scss 맨 위의 $cp-print-inset을 0에서 올리십시오. 하단 바는 페이지 가장자리에 그대로 남고 내용만 안쪽으로 들어갑니다.
